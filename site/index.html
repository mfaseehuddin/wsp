wsp · weight-space programming

Writing neural-network weights by understanding them

AI agents read, write and graft neural-network weights directly, with no training. Every result here comes from an agent working through a budgeted harness, scored on tests it never saw. This page updates as the work does.

GitHub repo Round 1 report (7 Nov) Roadmap

Our agent prompts follow the protocol in their published logs: diagnose, localize causally, edit, verify with paired measurements, explain every step.

Find how a pretrained model stores facts, write new facts in its own format with closed-form edits, then cut out a small, cheap support bot that runs locally.

round 1 done

D · Coarse-to-fine programming

Hand-write the weights of a Next-Concept Model, a generator that writes coarse to fine, every position of a level in parallel. The coarse levels hold the concept and the fine levels the words.

on hold

C · Latent function calling

A port inside the forward pass. A trigger direction fires, arguments are read from the residual stream, a real tool runs, and its result is written back as a vector. No text to parse.

Track A · round 1

Can an agent graft an exact adder into Qwen2.5-0.5B?

The unedited model adds short numbers well but fails from about 6 digits. Each agent gets the frozen weights, surgery helpers that add inert neurons, heads or layers, and a budget of 60 forward passes. The result must still load as a stock Hugging Face checkpoint. Scoring uses a hidden set: 960 problems of 1–12 digits in four prompt formats (two never seen), plus a guard on ordinary text.

Track D · round 1 · 8 Nov

The first hand-written Next-Concept Models

Two agents each wrote every weight of a small NCM help-desk bot, with no training. Each reply is built in levels: a forward pass per level, every position of a level in parallel. The bot answers 14 IT topics and must copy the user's name and ticket number into the reply. Scoring used 448 messages: new phrasings, names and templates that neither agent ever saw.

97.3%nco · Opusexact replies on 448 unseen messages · 2 forward passes per reply · 1.39M params (223k nonzero) · 4 runs, ~100k tokens
86.2%ncs · Sonnetexact replies · 2 forward passes per reply · 5.8M params (169k nonzero) · 7 runs, ~85k tokens
2levels, found independentlyBoth agents chose the same split: one plan code (intent × name? × ticket?), then all 48 reply tokens at once, written by template neurons and copy heads.

Try it: uv run wsp-ncm chat --agent nco · prompts: TASK.md · model: model.py

Use it

Start your own experiment

  1. Clone the repo and run uv sync (PyTorch on CPU, CUDA or Apple MPS).
  2. Pick a harness: wsp-llm (pretrained LLM surgery), wsp-gen, wsp-bot, wsp-support, wsp-pong.
  3. Point an agent (Claude Code, Codex, …) at the experiment's CHEATSHEET.md and TASK.md. Give it a budget of forward passes and tokens.
  4. Freeze the result, then score it on a hidden set written after the freeze. Audit the explanation by having a fresh agent extend the model from the docs alone.
git clone https://github.com/mfaseehuddin/wsp && cd wsp && uv sync
WSP_ADMIN=1 uv run wsp-llm init --agent me --budget 60 --tokens 400000
uv run wsp-llm eval --agent me --base --digits 8 --n 128
